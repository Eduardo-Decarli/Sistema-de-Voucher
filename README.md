# 🎟️ Sistema de Geração de Vouchers

Sistema backend completo para geração, validação e gerenciamento de **vouchers promocionais**, desenvolvido com **Node.js** e **MongoDB**.

---

## 🚀 Funcionalidades

- ✅ Geração automática de códigos únicos
- 🔒 Validação de vouchers
- 📆 Expiração por data ou uso
- 👤 Associação de voucher a usuário
- 📊 Listagem e filtros por status (ativo, expirado, usado)
- 🔐 Autenticação via JWT (opcional)

---

## 🧰 Tecnologias utilizadas

- [Node.js](https://nodejs.org/)
- [Express](https://expressjs.com/)
- [MongoDB](https://www.mongodb.com/)
- [Mongoose](https://mongoosejs.com/)
- [UUID](https://www.npmjs.com/package/uuid)
- [Dotenv](https://www.npmjs.com/package/dotenv)

---

## 📦 Instalação

1. Clone o projeto:

```bash
git clone https://github.com/seu-usuario/voucher-system.git
cd voucher-system
```

2. Instale as dependências:

``` bash

npm install

```

3. Inicie a Aplicação

``` bash

npm start

```
